# ButugiriButuri

教科書型の物理学サイトです。単元本文は左カラム、補足ノートは右カラムに表示されます。

## 起動

```bash
npm start
```

デフォルトでは [http://localhost:4173](http://localhost:4173) で起動します。

## 共有コメント

- 補足コメントは `/api/comments` に送信されます
- 保存先はローカルの `data/comments.json` です
- API に接続できない場合、フロントエンドはブラウザ内保存にフォールバックします

## 用語リンク

単元本文では次の記法で別単元へリンクできます。

- `[[遷移先単元]]`
- `[[遷移先単元|表示名]]`
